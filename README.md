# L4NG

Free apps for learning languages. No account, no ads, and they work offline once installed.

👉 **Open:** https://verkno.github.io/L4NG/

## Apps

| App | Language | Open |
|---|---|---|
| **C3KO** | Czech grammar, A1–C2, in English or Bahasa Indonesia | https://verkno.github.io/L4NG/c3ko/ |

Each app has its own folder with a README explaining how to use it.
